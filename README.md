🌮 Murder at Casa del Queso 💀

An interactive murder mystery party experience

Welcome to Murder at Casa del Queso, a hosted murder mystery experience designed for a fun, social party where guests take on characters, uncover clues, question suspects, and work together—or against each other—to solve a mysterious crime.

This project contains the interactive HTML experience used to help run the party.

🎭 What Is This?

Murder at Casa del Queso is a browser-based murder mystery experience created for an in-person party.

Guests are assigned characters with their own personalities, secrets, relationships, and potential motives. Throughout the experience, players can use clues and information revealed during the game to piece together what happened.

The goal isn’t just to figure out who committed the murder—it’s to stay in character, investigate suspicious behavior, protect your secrets, and enjoy the chaos along the way.

🖥️ How to Use

The main experience is contained in the HTML file included in this repository.

For the Host

1. Download or open the HTML file.
2. Open it in a web browser.
3. Use the interactive page as your party guide.
4. Follow the game instructions and reveal information as directed.
5. Keep any host-only information hidden from players until the appropriate point in the game.

For Players

Players should follow the instructions provided by the host and only access information intended for their character or stage of the game.

Important: Don’t read ahead if you’re playing! Spoilers may be contained within the files.

🕵️ Game Experience

The experience may include:

* Character introductions
* Character backgrounds and secrets
* Suspect information
* Clues and evidence
* Investigation prompts
* Story developments
* Interactive game sections
* Host instructions
* Final accusations
* Murder reveal and solution

The exact flow is intended to be discovered during the party rather than spoiled beforehand.

📁 Project Structure

The repository is intentionally lightweight.

The primary HTML file contains the interactive murder mystery experience and can be opened directly in a modern web browser without requiring a complicated installation process.

Additional files may be added as the experience evolves.

🌐 Running the Game

No special software or development environment is required.

Simply open the HTML file in a modern browser.

For the best experience, use a laptop, tablet, or other device with a reasonably sized screen.

⚠️ Spoiler Warning

This repository contains the murder mystery experience and may contain major story spoilers, including the identity of the murderer and the solution.

If you are participating as a player, avoid exploring the source files or reading sections intended for the host.

🎉 About the Project

Murder at Casa del Queso was created as a custom party experience designed to combine storytelling, role-playing, investigation, humor, and interactive gameplay.

The project is part of a larger interest in creating reusable, interactive event experiences that can eventually be adapted for different themes, groups, and occasions.
